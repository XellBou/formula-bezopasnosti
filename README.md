# 🛡️ Формула безопасности

Интеллектуальный веб-тренажёр по прикладной математике для курсантов колледжа гражданской защиты (МЧС).

**Ключевой принцип:** это тренажёр понимания, а не боевой инструмент для расчётов во время пожара.
Все модели учебные и упрощённые; для реальных расчётов используются нормативные документы и справочники.

## Модули

1. Пожарная физика — стандартная кривая ISO 834, время до общей вспышки.
2. Гидравлика — давление на насосе: подъём, потери в рукавах, давление на стволе.
3. Эвакуация — время эвакуации и сравнение с нормативом.
4. Нагрузки — прочность балки, коэффициент запаса, эпюра моментов.
5. Риск ЧС — статистическая вероятность и надёжность техники.
6. Тренажёр задач — задачи с проверкой ответа (допуск 5 %), подсказками и разбором.

Дополнительно: раздел «История» (сохранённые расчёты и попытки в тренажёре, SQLite).

## Установка и запуск

```bash
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt
python selfcheck.py             # необязательно: проверка расчётов
streamlit run app.py
```

Приложение откроется по адресу http://localhost:8501.

## Переменные окружения

| Переменная | Обязательна | Назначение |
| ---------- | ----------- | ---------- |
| `OPENAI_API_KEY` | нет | Ключ OpenAI. Без него работает демо-режим с шаблонными объяснениями. |
| `OPENAI_MODEL` | нет | Модель, по умолчанию `gpt-4o-mini`. |

```bash
export OPENAI_API_KEY="sk-..."   # Windows (PowerShell): $env:OPENAI_API_KEY="sk-..."
```

При деплое на Streamlit Community Cloud добавьте `OPENAI_API_KEY` в Secrets на верхнем уровне:
такие секреты доступны приложению как переменные окружения.

## Как добавить задачу в тренажёр

Откройте `modules/trainer.py` и добавьте словарь в список нужной темы в `TASKS`
(или создайте новую тему — новый ключ словаря):

```python
{
    "id": "hyd-4",                      # уникальный идентификатор
    "text": "Текст задачи…",
    "answer": 3.92,                     # правильный ответ (число)
    "unit": "атм",                      # единица измерения для подписи поля
    "hint": "Короткая подсказка.",
    "solution": "1. Первый шаг.\n2. Второй шаг.",
},
```

Ответ пользователя засчитывается при отклонении не более 5 % (константа `TOLERANCE`).
После добавления запустите `python selfcheck.py` — он проверит структуру задач и уникальность `id`.

## Ограничения

- Модели упрощённые, коэффициенты потерь в рукавах и пороги вердиктов — учебные.
- На хостингах с временной файловой системой (например, Streamlit Community Cloud)
  файл `data/tasks.db` сбрасывается при перезапуске; история общая для всех пользователей.
